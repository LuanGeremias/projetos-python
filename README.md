Este repositório reúne uma coleção de exercícios desenvolvidos em Python com o objetivo de fortalecer a lógica de programação e aprimorar habilidades na linguagem. Os desafios abordam desde conceitos básicos, como variáveis, condicionais e estruturas de repetição, até problemas mais elaborados que envolvem listas, funções e manipulação de dados.

O conteúdo foi organizado de forma progressiva, permitindo acompanhar a evolução no aprendizado e servir como material de estudo e revisão. Ideal para iniciantes e também para quem deseja praticar e consolidar seus conhecimentos em Python.

🚀 Tecnologias utilizadas: Python
📚 Foco: Lógica de programação e resolução de problemas
💡 Objetivo: Evolução contínua e prática consistente
